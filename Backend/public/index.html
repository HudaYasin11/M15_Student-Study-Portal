3. Getting started

Every request (except key generation) needs your key in the Authorization header:

Authorization: Bearer sk_live_your_key_here

Example — list your exams:

curl http://localhost:5000/api/v1/exams \
  -H "Authorization: Bearer sk_live_your_key_here"

Example — issue a certificate (JavaScript):

fetch("http://localhost:5000/api/v1/certificates", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk_live_your_key_here"
  },
  body: JSON.stringify({ resultId: 1 })
}).then(r => r.json()).then(console.log);

Example — subscribe to webhooks:

fetch("http://localhost:5000/api/v1/webhooks", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk_live_your_key_here"
  },
  body: JSON.stringify({ targetUrl: "https://your-app.com/webhook" })
}).then(r => r.json()).then(console.log);

Sandbox keys only ever see/create sandbox data — safe to experiment with. Switch to a live key when you're ready to go live.
